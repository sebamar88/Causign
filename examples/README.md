# Deterministic process examples

Build the workspace packages first. Every `.mjs` imports workspace packages through their built `dist` exports. These agents use fake functions, no provider, filesystem deletion, refund, or deployment effects. Set each agent configuration to `command: process.execPath`, `args: [absolutePathToAgent]`. Load each scenario's default export. The RAG evaluator configuration is `{module: absoluteFileUrlToEvaluator}`.

stdout is exclusively protocol JSONL. Use `context.diagnostic(text)` or stderr for application logs; `console.log` is deliberately not globally hijacked and would corrupt stdout. Cancellation closes all bridge decisions and signals `context.signal`. Custom functions must honor this signal to release their own resources; JavaScript cannot forcibly stop arbitrary promises or external effects which already started.

Support rejects a business approval. Coding and DevOps report local policy rejection and independently assert non-execution. `context.rejectTool(name,input,{source,reason})` emits a nonselected request and rejection then throws. Its source excludes runner-only `agentest`. Selected tool names cannot use this local helper: they require an explicit runner `tool.reject` decision, and this helper fails closed before reporting local rejection. RAG uses a deterministic structural evaluator, not a live semantic model. Coordinator exposes concurrent operations inside one run; bridge tests deliver their decisions in reverse order.

`instrument(context, name, execute)` wraps custom TypeScript functions. Optional `observations` enable message/model/usage hooks. `modelStarted` returns an operation ID required by `modelCompleted` or `modelFailed`. `reportUsage` records an explicit final aggregate; no cost capability or price inference is advertised. Approval observation may use `controlApprovals:false` with a local `approval(input, signal)` callback. Without a configured runner decision or local callback an approval errors; it never grants by default.

`fixtures/python-agent.py` is a small standard-library protocol fixture, not a Python SDK. Cross-language acceptance executes it and fails with instructions if Python is unavailable. Set `AGENTEST_PYTHON` to an absolute Python 3 executable if necessary.
